## Regle

Un guide ne decrit que l'usage prouve aujourd'hui.
Il ne decrit pas une cible future comme si elle etait deja utilisable.
Les guides `DOC_ONLY` sont des guides de lecture, pas des guides d'usage live.
Le guide `FORBIDDEN_LIVE` est une notice d'interdiction, pas un guide live.
