# Kanban Project Board

This folder fixes the project management workspace for the current planning cycle.

- Repo folder: `/opt/trading/docs/project_management/kanban`
- Working branch: `docs/kanban-pilotage-20260318`
- Scope: planning, tracking, and evaluating progress for the `student` / `deepseek_hub` / `/opt/trading` operating environment

Contents:

- `kanban_board.md`: full Kanban board in readable Markdown table format
- `kanban_board.csv`: spreadsheet-friendly export for LibreOffice / Excel
- `kanban_board_manager.md`: concise board-manager view
- `kanban_references.md`: source documents and evidence used to build the board

Recommended usage:

1. Use `kanban_board.md` for weekly review.
2. Use `kanban_board.csv` for filtering, sorting, and reporting.
3. Use `kanban_board_manager.md` for quick standups and decision meetings.
4. Use `kanban_references.md` when a card needs traceability back to evidence.
