# UI Target Map

## Catégories cibles

### 1. `ui/index/modules`
Registry lisible de tous les modules / surfaces UI.

### 2. `ui/dev`
Surfaces techniques, debug, wrappers, maintenance, vues non destinées à l’opérateur final.

### 3. `ui/probabilites_trades`
Surfaces axées :
- derivatives
- probability
- decision
- risk
- positions / portfolio
- scan / ranking

### 4. `ui/screenshots_analyses_passees`
Surfaces de navigation et conservation des captures + analyses liées.

## Placement machine cible
- **MSI** : quasi toutes les surfaces utilisateur/opérateur
- **admin-trading** : backend / services / exécution / production d’artefacts
- **Dell** : dev / orchestration / prompts / contrôle
- **student** : IA/complément/réflexion

## Candidats UI prioritaires après registry
1. `desk_pro_dashboard`
2. `deskpro_toolbox` (si distinct du hub CLI)
3. `perf_ui`
4. surface screenshots + analyses passées
5. surface probabilités / trades
