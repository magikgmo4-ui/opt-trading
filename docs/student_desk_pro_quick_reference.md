# Student Desk Pro - Quick Reference

| Action | Commande | Description |
|---|---|---|
| **Santé** | `sanity-desk-pro-student` | Vérifier l'état local du pack |
| **Status** | `desk-pro-student status` | Afficher les composants disponibles |
| **Shared** | `desk-pro-student-shared-info` | Lire le résumé du dernier run partagé |
| **Summary** | `desk-pro-student summary` | Afficher l'état local et le partage |
| **Menu** | `menu-desk-pro-student` | Interface interactive simple |

---
**Rôle** : Consultation / Vérification.
**Partage** : `/shared/desk_pro/latest/`
