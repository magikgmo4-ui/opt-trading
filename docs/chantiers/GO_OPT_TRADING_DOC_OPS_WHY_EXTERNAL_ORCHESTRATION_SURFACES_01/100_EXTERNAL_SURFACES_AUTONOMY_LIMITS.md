# 100_EXTERNAL_SURFACES_AUTONOMY_LIMITS

## Objectif

Verrouiller les limites d'autonomie des surfaces externes.

## Limites candidates

| Limite | Raison |
| --- | --- |
| aucun APPLY automatique | protection runtime |
| aucun merge automatique | governance humaine |
| aucune propagation implicite | explicabilite |
| aucune execution live autonome | criticite runtime |
| aucune promotion automatique R4/R5 | governance critique |

## Observation

Les surfaces externes doivent rester:
- assistives,
- explicables,
- auditables,
- reviewables humainement.

## Regles

- Toute automation doit etre explicite.
- Toute orchestration critique doit etre reviewee humainement.
- Toute source externe doit etre tracable.
- Toute propagation doit etre observable.

## Invariant

Aucune surface externe ne doit devenir une autorite runtime autonome.
