# 10_EXTERNAL_SURFACES_CLASSIFICATION

## Objectif

Classifier les surfaces externes candidates dans la governance WHY.

## Surfaces candidates

| Surface | Role potentiel | Classe candidate |
| --- | --- | --- |
| ClickUp | suivi taches / operations | R2/R3 |
| Botpress | agent conversationnel / workflow | R3 |
| Knowledge Graph | representation relations / verite projet | R3 |
| Airtable | base structuree / operations | R2/R3 |

## Lecture WHY

Ces surfaces peuvent devenir critiques si elles influencent:
- priorisation,
- orchestration,
- decisions IA,
- suivi de runtime,
- propagation de statut.

## Regle

Une surface externe ne doit pas etre promue runtime sans:
- role explicite,
- invariants,
- observabilite,
- reprise,
- review humaine.

## Invariant

Ces classifications restent candidates tant qu'aucune integration active n'est validee.
