# 06_TELEGRAM_OUTPUT

## Principe

Telegram ne doit pas recevoir tout le bruit. Le filtre doit privilegier les
sorties courtes, utiles et prioritaires.

## Sorties Telegram candidates

- resume court macro
- alertes breakout / breakdown
- squeeze risk
- watchlist candidates screener
- news catalyst urgent

## Regles de filtrage recommandees

- ne pas envoyer les captures brutes par defaut
- ne pas envoyer les analyses faible confiance
- favoriser les changements d'etat ou confirmations fortes
- grouper les outputs screener si plusieurs noms sont lies au meme theme

## Format cible

| Type | Format |
|---|---|
| chart alert | 3-5 lignes + niveau cle |
| liquidity alert | squeeze / funding / OI warning |
| macro alert | risk-on/off summary |
| screener alert | secteur + tickers + raison |
| news alert | catalyseur + urgence + actifs |
