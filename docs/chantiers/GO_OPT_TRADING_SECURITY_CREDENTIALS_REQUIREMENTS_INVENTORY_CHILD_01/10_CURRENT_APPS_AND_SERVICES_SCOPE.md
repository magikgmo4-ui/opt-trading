# Current Apps and Services Scope

L'inventaire couvre les surfaces suivantes :

## Services de Collecte
- **Telegram Collector**: Collecte de signaux et données depuis des canaux Telegram.
- **Market Data Readonly**: APIs de prix et métriques (Coinglass, Binance).

## Intégrations Externes
- **TradingView Webhook**: Réception d'alertes stratégiques.
- **Google Sheets**: Écriture et lecture de registres et journaux de bord.
- **GitHub**: Opérations sur les dépôts, PRs et gestion de flotte.

## Outils de Productivité & Analyse
- **DeskPro CLI/GUI**: Analyse de snapshots et gestion de bureau.
- **LLM Local (Ollama)**: Inférence locale pour revue de code et analyse.
- **LLM Cloud (OpenAI, Anthropic, Gemini)**: Inférence externe pour tâches complexes.

## Infrastructure
- **Data Center**: Accès aux bases de données et stockage persistant.
- **Access Management**: SSH, WireGuard (credentials d'accès à l'infrastructure).
