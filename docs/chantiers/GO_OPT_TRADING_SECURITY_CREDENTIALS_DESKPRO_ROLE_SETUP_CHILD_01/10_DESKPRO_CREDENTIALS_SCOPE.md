# DeskPro Credentials Scope

Le rôle `deskpro_user` concerne l'accès aux outils de tableau de bord et d'analyse DeskPro.

| Credential ID | Env Var | Type | Description |
|---------------|---------|------|-------------|
| `deskpro_api_url` | `DESKPRO_API_URL` | `url` | URL de l'API DeskPro. |
| `deskpro_api_key` | `DESKPRO_API_KEY` | `api_key` | Clé API DeskPro. |

## Variables de Configuration
- `DESKPRO_SNAPSHOT_DIR`: Chemin local vers les snapshots d'analyse.
- `DESKPRO_GUI_ENABLED`: Activation de l'interface graphique (0/1).
