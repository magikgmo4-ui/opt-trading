## 4_Anomalies Documentées

### Anomalie send-keys / utilisateur openclaw

**Description:** Lancer `tmux send-keys` avec commande gateway via un autre utilisateur (ex: `ghost`) échoue car `cmd.sh start` vérifie `TARGET_USER=openclaw`.

**Résolution:** Utiliser `cmd.sh start` qui gère automatiquement `sudo -u openclaw`.

**Impact:** Limité à la méthode d'invocation. Le runtime via `cmd.sh start` fonctionne.
