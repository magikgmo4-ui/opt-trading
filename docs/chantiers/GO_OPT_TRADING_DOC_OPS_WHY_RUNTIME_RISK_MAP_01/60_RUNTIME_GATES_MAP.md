# 60_RUNTIME_GATES_MAP

## Objectif

Cartographier les gates humaines et documentaires runtime.

## Gates critiques

| Gate | Surface | Role |
| --- | --- | --- |
| PASS/FAIL | toutes | validation explicite |
| AUDIT/APPLY | runtime critique | separation verification/execution |
| review humaine | R4/R5 | protection anti-derive |
| reprise obligatoire | R3/R4/R5 | continuite |
| preuves runtime | runtime | validation reelle |
| verification machine split | multi-machine | anti-collision |
| verification parent produit | gouvernance | coherence fonctionnelle |

## Gates recommandees par classe

| Classe | Gates minimales |
| --- | --- |
| R0 | reprise |
| R1 | WHY recommande |
| R2 | PASS/FAIL |
| R3 | PASS/FAIL + reprise |
| R4 | review humaine + preuves runtime |
| R5 | review forte + governance complete |

## Observation

Les gates existent pour ralentir les erreurs critiques avant execution.
