# LLM Local Credentials Scope

Le rôle `llm_local` concerne l'accès aux serveurs d'inférence IA locaux (ex: Ollama).

| Credential ID | Env Var | Type | Description |
|---------------|---------|------|-------------|
| `ollama_base_url` | `OLLAMA_BASE_URL` | `url` | URL de base du serveur Ollama. |

## Variables de Configuration
- `LOCAL_MODEL_NAME`: Nom du modèle local à utiliser par défaut (ex: `mistral`, `llama3`).
