# 120_WHY_WORKER_AUTONOMY_LIMITS

## Objectif

Verrouiller les limites d'autonomie IA/runtime du futur worker WHY.

## Limites principales

| Limite | Raison |
| --- | --- |
| aucun APPLY | protection runtime |
| aucun merge automatique | governance humaine |
| aucun FAIL runtime autonome | protection surfaces critiques |
| aucune correction documentaire | non destructif |
| aucune validation live | review humaine obligatoire |

## Surfaces critiques

Les surfaces R4/R5:
- doivent garder review humaine,
- doivent garder observabilite,
- doivent garder preuves runtime,
- ne doivent jamais dependre uniquement du worker WHY.

## Observation

Le worker WHY doit rester:
- audit-oriented,
- explicable,
- documentaire,
- non destructif.

## Invariant final

Le worker WHY ne doit jamais devenir une autorite autonome de governance runtime.

## RISKS

- À qualifier.
