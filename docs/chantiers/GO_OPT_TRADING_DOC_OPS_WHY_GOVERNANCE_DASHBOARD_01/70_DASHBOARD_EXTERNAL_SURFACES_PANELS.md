# 70_DASHBOARD_EXTERNAL_SURFACES_PANELS

## Objectif

Definir les panneaux surfaces externes du futur WHY governance dashboard.

## Panneaux candidats

| Panel | Role |
| --- | --- |
| CLICKUP_STATUS | suivi orchestration externe |
| BOTPRESS_RELATIONS | orchestration conversationnelle |
| KNOWLEDGE_GRAPH_RELATIONS | coherence relationnelle |
| AIRTABLE_COORDINATION | operations structurees |
| EXTERNAL_RISK_MAP | risques surfaces externes |
| EXTERNAL_REVIEW_GATES | review humaine externe |

## Regles

- Les surfaces externes doivent rester contextualisees.
- Les relations externes doivent etre auditables.
- Les surfaces critiques doivent afficher leurs limites.
- Les gates humaines doivent rester visibles.

## Invariant

Les surfaces externes ne doivent jamais devenir des orchestrateurs runtime autonomes via le dashboard.
