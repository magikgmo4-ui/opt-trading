# 90_DASHBOARD_AUTONOMY_LIMITS

## Objectif

Verrouiller les limites d'autonomie du futur WHY governance dashboard.

## Limites principales

| Limite | Raison |
| --- | --- |
| aucun APPLY automatique | protection runtime |
| aucun merge automatique | governance humaine |
| aucune validation runtime autonome | protection surfaces critiques |
| aucune promotion automatique R4/R5 | criticite runtime |
| aucune correction documentaire autonome | audit only |

## Regles

- Le dashboard visualise et contextualise.
- Le dashboard ne decide pas seul.
- Le dashboard ne corrige pas seul.
- Le dashboard ne valide pas le runtime.
- Le dashboard ne remplace pas une review humaine.

## Invariant

Le dashboard WHY reste une aide d'audit et de visualisation, jamais une autorite autonome.

## RISKS

- À qualifier.
