# 10_STEPS

1. Définir la page automation overview (état global, dernière exécution, alertes)
2. Définir la page workers state (liste des workers, statut, dernière tâche)
3. Définir la page jobs queue (file d'attente, en cours, terminé, échoué)
4. Définir la page approvals (propositions en attente, historique)
5. Définir la page ledger (events, filtre, recherche, replay)
6. Définir la page signals (derniers signaux, source, confiance)
7. Définir les safe buttons (boutons read-only, restart contrôlé)
8. Définir le kill switch (visuel, confirmation, périmètre)
