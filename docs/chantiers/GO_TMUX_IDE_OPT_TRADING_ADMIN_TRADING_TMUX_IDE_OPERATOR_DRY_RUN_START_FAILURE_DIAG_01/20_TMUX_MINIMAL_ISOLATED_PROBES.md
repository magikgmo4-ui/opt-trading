# 20_TMUX_MINIMAL_ISOLATED_PROBES

## 1_MASTER_TARGET

Verifier `tmux` avec une config neutre et un socket dedie, sans toucher au serveur tmux global.

## 2_SOCKET

Socket dedie :

```text
opt-trading-diag-baseline-01
```

Commandes :

```bash
tmux -f /dev/null -L opt-trading-diag-baseline-01 new-session -d -s opt-trading-diag 'sleep 5'
tmux -L opt-trading-diag-baseline-01 ls
tmux -L opt-trading-diag-baseline-01 display-message -p -t opt-trading-diag '#S #{session_windows}'
tmux -L opt-trading-diag-baseline-01 kill-session -t opt-trading-diag
tmux -L opt-trading-diag-baseline-01 ls
```

## 3_RESULTS

```text
TMUX_MINIMAL_NEW_EXIT=0
opt-trading-diag: 1 windows
opt-trading-diag 1
%0|sleep|0
post-kill: no server running on /tmp/tmux-1000/opt-trading-diag-baseline-01
```

## 4_INTERPRETATION

```text
TMUX_MINIMAL_ISOLATED_PASS=YES
TMUX_SOCKET_DEDICATED_PASS=YES
TMUX_GLOBAL_SERVER_NOT_REQUIRED=YES
```

This isolates the failure away from:

- missing `tmux` binary ;
- Debian 12 package incompatibility ;
- broken `/tmp/tmux-UID` permissions ;
- need for a pre-existing tmux server ;
- user/global tmux config for the minimal case, because `-f /dev/null` was used.
