# 90_CONVERGENCE_AUTONOMY_LIMITS

## Objectif

Verrouiller les limites d'autonomie convergentes des couches WHY.

## Limites principales

| Limite | Raison |
| --- | --- |
| aucun APPLY automatique | protection runtime |
| aucun merge automatique | gouvernance humaine |
| aucun worker runtime autonome | criticite runtime |
| aucun dashboard live autonome | review humaine |
| aucun lint bloquant sans phase validee | experimentation controlee |
| aucune promotion automatique R4/R5 | anti derive critique |

## Regles

- Les composants WHY doivent rester audit-oriented.
- Les surfaces R4/R5 doivent garder review humaine.
- Les decisions runtime doivent rester explicitement validees.
- Les preuves runtime doivent rester tracables.

## Invariant

La convergence WHY ne doit jamais devenir une autorite runtime autonome.

## RISKS

- À qualifier.
