# 40_USAGE

## Command
`python3 scripts/ai/workers/doc_ops_create_chantier.py --go-id GO_MY_NEW_PROJECT_01`

## Options
- `--summary "Short description"`: Add to the initial doc.
- `--create-inbox`: Create `docs/index/inbox/GO_MY_NEW_PROJECT_01.md`.
- `--dry-run`: Simulation mode.
- `--json`: Machine-readable output.
- `--force`: Overwrite existing files.
