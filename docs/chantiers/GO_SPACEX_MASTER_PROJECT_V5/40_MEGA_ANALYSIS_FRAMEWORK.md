# Mega Analysis Framework

## Score stack

| Score | Role |
|---|---|
| Momentum | IPO gap, VWAP, ORB, relative volume |
| Smart money | FVG/BOS/CHOCH/OB/liquidity |
| News velocity | article count + catalyst severity |
| Institutional | ETF/analyst/13F/lockup changes |
| Risk | valuation stress, halt risk, crowding |
| Trade-ready | momentum + smart money + catalyst - risk |
| Accumulation | fair-value zone + long-term catalyst + reduced risk |

## Decision outputs

- WATCH
- TRADE_READY_WATCH
- WAIT_PULLBACK
- ACCUMULATION_ZONE_WATCH
- DANGER_ZONE
- NO_TRADE
