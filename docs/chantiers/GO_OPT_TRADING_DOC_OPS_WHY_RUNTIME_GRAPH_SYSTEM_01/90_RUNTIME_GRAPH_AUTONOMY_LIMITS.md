# 90_RUNTIME_GRAPH_AUTONOMY_LIMITS

## Objectif

Verrouiller les limites d'autonomie du futur WHY runtime graph.

## Limites principales

| Limite | Raison |
| --- | --- |
| aucun APPLY automatique | protection runtime |
| aucun merge automatique | governance humaine |
| aucune validation runtime autonome | protection surfaces critiques |
| aucune promotion automatique R4/R5 | criticite runtime |
| aucune inference machine non prouvee | anti hallucination |

## Regles

- Le graphe represente des relations documentees.
- Le graphe ne decide pas seul.
- Le graphe ne corrige pas seul.
- Le graphe ne valide pas un runtime.
- Le graphe ne remplace pas une review humaine.

## Surfaces critiques

Les surfaces R4/R5 doivent garder:
- review humaine,
- preuves runtime,
- observabilite,
- reprise.

## Invariant

Le WHY runtime graph reste une aide d'audit et de visualisation, jamais une autorite autonome.
