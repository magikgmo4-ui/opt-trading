# GO_OPT_TRADING_JOURNAL_CANON_INTENT_LAYER_04

## Objet

Reprendre la lecture du journal canon en changeant explicitement l’angle d’extraction.

Le chantier précédent a produit une couche humaine solide sur les méthodes de travail, la continuité, la reprise, les clôtures, les couches et la gouvernance documentaire.

Le problème restant est le suivant : cette extraction ne couvre pas encore suffisamment l’intention humaine portée par les projets eux-mêmes.

Le présent GO vise donc une lecture orientée prioritairement sur :
- l’objectif réel par projet ou sous-projet
- l’intention humaine formulée ou implicite
- le plan validé ou la trajectoire voulue
- les choix structurants
- le pourquoi de ces choix
- les arbitrages entre options
- les raisons de non-choix
- les liens entre méthode de travail et but projet

## Constat de départ retenu

La couche déjà extraite depuis le journal canon ressort majoritairement sur :
- continuité
- reprise
- validation
- couches documentaires
- autorité
- clôture
- réversibilité
- opérabilité

Cette matière est utile mais reste orientée méthode.

Il manque encore une extraction plus directe de :
- ce que les projets cherchaient à accomplir
- pourquoi ils existaient
- comment les choix ont été arbitrés
- à quel plan validé ils se rattachaient
- quelle intention humaine réelle traversait ces chantiers

---

## Règle de lecture pour ce GO

À partir de maintenant, lors de la lecture du journal canon, la priorité d’extraction est la suivante :

1. intention humaine du projet
2. objectif réel
3. plan validé / trajectoire voulue
4. choix structurants
5. raisons et arbitrages
6. seulement ensuite méthodes et continuité si elles éclairent le projet

Autrement dit, la méthode n’est plus le centre.
Elle n’est retenue que lorsqu’elle éclaire le but projet.
