# OT-PROMPT-02 — STARTER PACK REPORT

## 1. OBJECTIF
Créer un kit de démarrage standardisé pour les missions Trae, afin de capitaliser sur les audits récents et d'éviter les régressions.

## 2. STRUCTURE CRÉÉE
Le pack est localisé dans `docs/master_pack/mission_starter_pack/` :
1.  **`00_mission_start_guide.md`** : Guide de lecture prioritaire (Sources de vérité, Règles d'or).
2.  **`01_mission_template.md`** : Canevas de mission prêt à copier (Contexte, Plan, Livrables).
3.  **`02_validation_checklist.md`** : Liste de vérification avant clôture (Sécurité Runtime, Doc).

## 3. VALEUR AJOUTÉE
- **Anti-Dérive** : Force la lecture des matrices d'exception dès le début.
- **Gain de Temps** : Évite de redécouvrir à chaque fois quels sont les bons entrypoints.
- **Uniformité** : Standardise le format des rapports de clôture.

## 4. USAGE
Toute nouvelle mission doit commencer par :
> "Applique le protocole du Starter Pack (docs/master_pack/mission_starter_pack/00_mission_start_guide.md)."

**Status : PACK DÉPLOYÉ.**
