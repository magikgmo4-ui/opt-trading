PAIR MARKET SNAPSHOT V1
DATE: 2026-03-18

PURPOSE
Canonical normalized entity for pair-centric exchange market snapshots.

TOP-LEVEL REQUIRED FIELDS
- contract_version
- schema_version
- module_id
- provider_id
- run_id
- generated_at
- entity_type
- records

TOP-LEVEL FIELD SEMANTICS
- contract_version: canonical artifact contract version, fixed to v1
- schema_version: normalized schema version, fixed to v1.0 for this entity contract
- module_id: collector module identifier
- provider_id: data provider identifier
- run_id: unique run identifier for the published snapshot
- generated_at: UTC ISO 8601 Z publication timestamp for this normalized artifact
- entity_type: fixed string `pair_market_snapshot`
- records: ordered list of market-pair snapshot records

RECORD ORDER RULE
- records must follow the configured provider pair allowlist order for deterministic downstream consumption.

RECORD REQUIRED FIELDS
- pair_symbol
- base_asset
- quote_asset
- trading_status
- is_spot_trading_allowed
- last_price
- open_price_24h
- high_price_24h
- low_price_24h
- price_change_percent_24h
- volume_base_24h
- volume_quote_24h
- trade_count_24h
- window_open_at
- window_close_at
- source

RECORD OPTIONAL FIELDS
- weighted_avg_price_24h

RECORD FIELD SEMANTICS
- pair_symbol: canonical pair identifier for the current provider module, typically matching the exchange symbol used for request filtering
- base_asset: base asset symbol for the pair
- quote_asset: quote asset symbol for the pair
- trading_status: provider trading-status value for the pair at discovery time
- is_spot_trading_allowed: whether the provider indicates the pair is available for spot trading
- last_price: latest pair price as a decimal string in quote_asset units
- open_price_24h: 24-hour opening price as a decimal string in quote_asset units
- high_price_24h: 24-hour high price as a decimal string in quote_asset units
- low_price_24h: 24-hour low price as a decimal string in quote_asset units
- price_change_percent_24h: 24-hour percentage price change as a decimal string
- volume_base_24h: 24-hour traded volume in base_asset units as a decimal string
- volume_quote_24h: 24-hour traded volume in quote_asset units as a decimal string
- trade_count_24h: integer count of trades in the 24-hour window
- window_open_at: UTC ISO 8601 Z opening timestamp for the provider 24-hour window
- window_close_at: UTC ISO 8601 Z closing timestamp for the provider 24-hour window
- weighted_avg_price_24h: provider weighted average price across the 24-hour window as a decimal string when supplied
- source.provider_symbol: provider-specific symbol carried through without redefining the canonical surface

SOURCE OBJECT RULE
- source is required.
- source must contain `provider_symbol`.
- provider-specific carry-through stays inside source and must not replace canonical fields.

COMPATIBILITY RULES
- Additive optional fields may be introduced in v1.x.
- Existing required fields and meanings must remain stable throughout schema major version v1.
