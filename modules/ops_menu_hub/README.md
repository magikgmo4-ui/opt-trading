# ops_menu_hub — hub unique pour tous tes menus/shortcuts

## Objectif
- détecter le host
- lister modules + menus disponibles
- lister shortcuts existants (menu-*/cmd-*/sanity-*)
- optionnel: créer automatiquement les shortcuts manquants

## Machines (Linux)
- admin-trading (Debian)
- student (Debian)
- db-layer (Ubuntu)

Sur Windows (cursor-ai), ce hub ne s’exécute pas tel quel.

## Usage
- `menu-ops_hub` (après install_shortcuts)
- `cmd-ops_hub list`
- `cmd-ops_hub bootstrap_shortcuts` (sudo)
