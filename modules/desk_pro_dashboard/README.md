# Desk Pro Dashboard

The Desk Pro Dashboard is the primary visualization layer for the Desk Pro trading system. It aggregates outputs from the Orchestrator runs into a unified view.

## Purpose
- **Visualize**: Display key portfolio metrics, active positions, and risk status.
- **Report**: Generate HTML/JSON snapshots of the system state.
- **Monitor**: Provide a quick "at a glance" status of the entire desk.

## Structure
- `app/`: Python source code (rendering logic).
- `config/`: Configuration templates and sample data.
- `scripts/`: Standard shell wrappers (`cmd.sh`, `menu.sh`, `sanity_check.sh`).

## Usage
Use the provided scripts in `scripts/`:
- `menu.sh`: Interactive menu for dashboard operations.
- `cmd.sh`: CLI wrapper for automation.
- `sanity_check.sh`: Validate installation and functionality.

## CLI Commands
```bash
# Check module status
./scripts/cmd.sh status

# Run with legacy sample data (no run required)
./scripts/cmd.sh sample

# Render the latest orchestrator run
./scripts/cmd.sh render-latest

# Render a specific run directory
./scripts/cmd.sh render-run --run-dir data/desk_runs/desk_run_20260306_181500

# Export dashboard to JSON (defaults to latest run)
./scripts/cmd.sh export-json

# Export dashboard to HTML (defaults to latest run)
./scripts/cmd.sh export-html
```

## Integration
- **Upstream**: Reads `data/desk_runs/` generated by `desk_pro_orchestrator`.
- **Downstream**: Can be served via web server or emailed as reports.

## Output Formats
- **Terminal**: ASCII table and summary.
- **JSON**: Structured view model.
- **HTML**: Simple, self-contained report with CSS styling.
